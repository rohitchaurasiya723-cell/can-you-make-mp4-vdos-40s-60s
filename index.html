How To Generate 40s - 60s MP4s with Code

Run this script in terminal or server to render MP4s automatically.

Terminal Command 
# Generate a 45-second vertical MP4 with music and graphics:
node generate-video.js 45 public/my_video.mp4

# Generate a 60-second video:
node generate-video.js 60 public/my_video_60s.mp4

FFmpeg Command Used Internally:

ffmpeg -y \
  -f rawvideo -vcodec rawvideo -s 720x1280 -pix_fmt rgba -r 30 -i - \
  -i soundtrack.wav \
  -c:v libx264 -pix_fmt yuv420p -preset fast -crf 21 \
  -c:a aac -b:a 192k \
  -movflags +faststart \
  -shortest output.mp4
💡 Why `-movflags +faststart` matters:

This moves the MP4 atom header (moov) to the beginning of the file, allowing iOS Safari, web browsers, and social networks to start playing the 45s-60s video immediately before the entire file finishes downloading!
